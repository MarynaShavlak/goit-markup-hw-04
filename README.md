# goit-markup-hw-04

Навчальний проєкт у межах курсу **GoIT** — Модуль 4 «Декоративні ефекти.
Анімація». Продовження верстки лендингу **WebStudio**: до розкладки з ДЗ-3 додано
**векторні іконки** (SVG-спрайт), **фонове зображення з градієнтним
затемненням**, **псевдоелементи**, **позиціонування** та **CSS-переходи** точно
за макетом.

**Демо:** https://marynashavlak.github.io/goit-markup-hw-04/

## Опис

Сторінку зверстано за макетом із дотриманням семантики HTML та оформлено за
допомогою CSS. Складається з таких блоків:

- **Header** — логотип `WebStudio`, навігація (`Features`, `Team`, `Portfolio`)
  та контакти. Активне посилання виділене кольором і підкресленням через
  псевдоелемент `::after`
- **Hero** — заголовок і кнопка `Order Service` на великому зображенні із
  затемненням (багатошаровий фон: лінійний градієнт `rgba(46, 47, 66, 0.7)` +
  зображення). Ширина фону обмежена оригінальними `1440px`
- **Features** — чотири переваги компанії; над кожним заголовком іконка у світлій
  декоративній рамці (заголовок секції прихований патерном `sr-only`)
- **Our Team** — чотири картки з фото, посадами та іконками соцмереж; картки
  мають постійну тінь
- **Our Portfolio** — шість проєктів-карток; при наведенні з'являється тінь, а
  знизу виїжджає синій оверлей з описом
- **Footer** — логотип із гаслом і блок «Social media» з іконками соцмереж

## Іконки

- Усі іконки — векторна графіка у форматі **SVG**, зібрана у спрайт
  `images/icons.svg` (сервіс **Icomoon**, оптимізація **SVGOMG**)
- Іконки додаються в розмітку через теги `<svg>` та `<use>` з явними `width` і
  `height`; колір задається властивістю `fill` на елементі `<svg>`

## Ефекти та анімація

- Усі переходи `:hover` / `:focus` (колір, фон, тінь, зсув) виконано з часом
  `250ms` і функцією `cubic-bezier(0.4, 0, 0.2, 1)`
- У `transition` явно зазначені анімовані властивості (без значення `all`)
- Псевдоелементи використані лише для декору (порожній `content`)

## Технології

- HTML5 (семантична розмітка), SVG-спрайт
- CSS3 — Flexbox, блокова модель, позиціювання, псевдоелементи, `transition`,
  багатошарові фони та градієнти, стани `:hover` / `:focus`
- [modern-normalize](https://github.com/sindresorhus/modern-normalize) —
  нормалізація стилів
- [Google Fonts](https://fonts.google.com/) — `Roboto` та `Raleway`
- [Prettier](https://prettier.io/) — форматування коду

## Організація стилів

У `index.html` підключається лише `css/main.css`, який імпортує решту файлів у
визначеному порядку:

```
@import './common.css';
@import './socials.css';
@import './header.css';
@import './hero.css';
@import './features.css';
@import './team.css';
@import './portfolio.css';
@import './footer.css';
```

Глобальні та базові стилі описані в `common.css`, спільні стилі списків соцмереж —
у `socials.css`, стилі конкретних блоків — у відповідних файлах.
